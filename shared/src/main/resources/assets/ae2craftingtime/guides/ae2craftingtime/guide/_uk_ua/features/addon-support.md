# Підтримка аддонів

Хімічні ключі Applied Mekanistics використовують ті самі мілівідра, що й
рідини AE2, тому швидкість і TTC лишаються змістовними. Сумісні crafting CPU з
AdvancedAE, NeoEco та AE2 Lightning Tech також можуть передавати звичайні події
профілювання на підтримуваних версіях.

Наприклад, підтримуваний CPU аддона з хімічним рецептом навчає історію мережі й
результату, а потім показує TTC на звичайних екранах AE2. Аддони не стають
обов'язковими: якщо один відсутній або несумісний, мод пропускає лише його
адаптер. Екрани аддона не отримують позначки без окремо зазначеної UI-інтеграції.
Після зміни встановленої версії аддона потрібен перезапуск.

![Необов'язковий Crafting Tree використовує спільні дані TTC](images/crafting-tree-tooltip.png)

*Тестова підказка показує, як необов'язковий аддон читає ту саму серверну статистику.*
