# ME Requester

З ME Requester на Minecraft 1.20.1 або 1.21.1 кожен рядок запиту може показувати
TTC під полями кількості, а заголовок — суму відомих видимих рядків. Оцінюється
лише поточна нестача в мережі: запитана кількість мінус уже збережена.

Наприклад, для запиту 64 діамантів, коли 48 уже є, оцінюються 16, які треба
створити. Якщо є вся кількість, позначки немає. Якщо є нестача без навченої
швидкості, рядок показує **No data yet**. Видимі рядки мають ті самі відносні
кольори, що й екрани AE2. У версії 26.1.2 інтеграції немає; без ME Requester
вона нічого не змінює.

![Рядок і загальний TTC у ME Requester](images/me-requester-estimate.png)

*Тестовий запит діамантів показує двосекундну оцінку рядка та загальний час.*
