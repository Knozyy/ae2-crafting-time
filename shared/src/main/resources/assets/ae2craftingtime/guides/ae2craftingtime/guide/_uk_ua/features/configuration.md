# Налаштування

Серверні налаштування зберігаються в
`<world>/serverconfig/ae2craftingtime-server.toml`. Коли запускається світ,
відсутній файл створюється автоматично. В одиночній грі `<world>` — це
збереження в `saves`, а на виділеному сервері — світ, вибраний через
`level-name`. Якщо в `config/ae2craftingtime-common.toml` є старі серверні
налаштування, до нового файлу потраплять їхні коректні значення, а для решти
параметрів — типові. Старий файл лишається на місці. Наявний файл світу під
час запуску не переписується.

Клієнтські налаштування зберігаються в
`config/ae2craftingtime-client.toml`.

У Клієнт → Вигляд параметр **Тінь тексту** керує тінню тексту, який малює AE2
Crafting Time. Типово тінь увімкнена. Вимкніть її, якщо хочете плаский текст.
Текст самого AE2 зберігає власні налаштування тіні. У клієнтському файлі також
можна задати `textShadow = false`.

**Тло позначок** у тому самому розділі Клієнт → Вигляд типово ввімкнене.
Вимкніть його, щоб приховати заокруглене тло позначок AE2 Crafting Time,
залишивши текст видимим. Тло вікон, рядків і підказок самого AE2 не зміниться.
Вибрані колір і прозорість позначок зберігаються: після повторного ввімкнення
тло матиме той самий вигляд. У клієнтському файлі також можна задати
`badgeBackground = false`.

Якщо **Тло позначок** і **Кольори від швидкого до повільного** вимкнені, звичайні
оцінки часу та стислі кількості в плані й стані виготовлення мають той самий
колір тексту, що й сусідні кількості AE2. Це працює і для підсвічених рядків.
Позначки збору даних, очікування, затримки й блокування зберігають свої кольори
попереджень. Стислі кількості поруч із ними мають колір відповідної позначки.
Вибрані кольори та прозорість тла лишаються збереженими після вимкнення
будь-якого з параметрів. Для стислих кількостей це діє і без профілювання.

- `enabled` вмикає профілювання та серверну статистику.
- `showInTree` керує позначками, підказками й кліками Crafting Tree на
  підтримуваних версіях до 26.
- `showChatMessages` керує подробицями й підтвердженням скидання, але не блокує
  саме скидання.
- `maxSamples` зберігає 1–100 зразків; типове значення — 10.
- `outlierMultiplier` приймає 1.0–1000.0; типове значення — 4.0.

Наприклад, `maxSamples = 20` збереже довшу недавню історію. Після зміни вікна
зразків або межі викидів перезапустіть гру чи сервер. Некоректні поля лишають
типові значення; числа поза допустимим діапазоном відхиляються.
